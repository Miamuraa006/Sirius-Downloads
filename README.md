# Sirius Desktop — скачать для Windows

**Sirius** — локальный голосовой помощник и управление Windows. Работает без облачной модели, Python устанавливать не нужно.

## Скачать

**[Скачать актуальный установщик Sirius](https://github.com/Miamuraa006/Sirius-Downloads/releases/latest)**

1. Откройте ссылку выше и скачайте `Sirius-Setup-0.5.1.exe` из блока **Assets**.
2. Запустите установщик на Windows 10 или Windows 11 **x64** и следуйте шагам установки.
3. После установки нажмите **Alt+M** или скажите **«Сириус»**. В чате команда `help` показывает поддерживаемые команды.

Модель распознавания речи и зависимости включены. Интернет для обычного использования не требуется.

**Внимание:** установщик не подписан коммерческим сертификатом. Windows может показать предупреждение о неизвестном издателе. Скачивайте только с этой страницы и сверяйте SHA-256 из `SHA256SUMS.txt` в релизе.

Это репозиторий **готовых установщиков**, без исходников и личных данных. Исходники развиваются отдельно.
